إليك البرومبت المعدّل بالكامل ليصبح باللغة العربية، مصمماً خصيصاً للتوجيه لبناء منصة تجارة إلكترونية متكاملة لماركة ROMA مع دعم الاتجاه من اليمين إلى اليسار (RTL)، التصميم الفاخر، القواعد، وربط أرمكس:

نص البرومبت (Prompt):
Role & Objective:
تعمل كمهندس برمجيات شمولية (Senior Full-Stack Developer) ومصمم واجهات مستخدم (UI/UX Designer). المطلوب إنشاء كود وبرمجية كاملة لمنصة تجارة إلكترونية متكاملة وجاهزة للإطلاق باللغة العربية لماركة مستحضرات تجميل وعناية بالبشرة فاخرة باسم "ROMA"، مع دعم كامل للاتجاه من اليمين إلى اليسار (RTL).

1. الهوية البصرية والتصميم (UI/UX - RTL)
اسم العلامة التجارية: ROMA (مستحضرات تجميل وعناية بالبشرة).

اللغة والاتجاه: اللغة العربية بالكامل مع دعم اتجاه النصوص من اليمين إلى اليسار (dir="rtl").

الطابع البصري: أنيق، عصري، فخم، ومريح للعين.

لوحة الألوان (Color Palette): الوردي الذهبي الناعم (Soft Rose Gold)، الوردي الفاتح (Pastel Pink)، ألوان النود الدافئة (Warm Nude)، الأبيض العاجي (Off-white)، مع الفحم الداكن للنصوص والخطوط.

الخطوط: خطوط عربية حديثة وفاخرة مثل (Cairo أو Tajawal أو Readex Pro).

أقسام الصفحة الرئيسية:

الشريط العلوي (Header): شريط إعلانات متحرك، القائمة الرئيسية، شعار ROMA، بحث ذكي مع اقتراحات فورية، محدد العملة، سلة التسوق الجانبية (Sliding Cart Drawer)، وقائمة المفضلة.

القسم الرئيسي (Hero Section): بنر جذاب بصورة عالية الجودة، شعار تسويقي، وزران لإجراء اتخاذ قرار: ("تسوقي المجموعة"، "اكتشفي منتجات العناية").

الأقسام الرئيسية (Categories): كروت تفاعلية للأقسام (أحمر الشفاه، كريم الأساس، العناية بالبشرة، مكياج العيون، العطور).

الأكثر مبيعاً والتوصلات الحديثة: شبكة منتجات مع خيار المعاينة السريعة (Quick View)، مكوّن تحديد الدرجة/اللون (Color Swatches)، تقييمات بالنجوم، وزر "إضافة إلى السلة" الفوري.

قصة العلامة وقيمها: قسم يبرز المكونات الآمنة، عدم التجربة على الحيوانات (Cruelty-Free)، والتغليف الصديق للبيئة.

آراء العملاء: شريط متحرك لمراجعات وتجارب العميلات مع شارات المشتري المؤكد.

الذيل (Footer): الاشتراك في النشرة البريدية، روابط التواصل الاجتماعي، سياسات الخصوصية والإرجاع، وشارات وسائل الدفع والشحن.

2. الخصائص والمنطق البرمجي للجرام (E-Commerce Logic)
صفحة تفاصيل المنتج (PDP): معرض صور مع تكبير (Zoom)، محدد تفاعلي لدرجة اللون/الشيد، تبويب شرح المكونات وطريقة الاستخدام، حالة المخزون، واقتراحات المنتجات المكملة.

حسابات المستخدمين: تسجيل الدخول والتسجيل (البريد أو التواصل الاجتماعي)، لوحة تحكم العميل (تتبع الطلبات، العناوين المحفوظة، قائمة المفضلة).

إتمام الشراء (Checkout):

عملية شراء متعددة الخطوات أو في صفحة واحدة مع دعم الشراء كزائر.

حساب تكلفة الشحن الدولي التلقائي بناءً على الدولة والوزن.

تطبيق أكواد الخصم ونقاط الولاء.

3. هيكلة قاعدة البيانات (Database Schema)
تقديم مخطط شامل لقاعدة البيانات (PostgreSQL / Prisma ORM أو MongoDB) يحتوي على والجداول/النماذج التالية:

المستخدمين (Users): id, name, email, password_hash, phone, role, addresses.

المنتجات (Products): id, name_ar, slug, description_ar, price, discount_price, stock_quantity, category_id.

درجات/خيارات المنتج (Variants): id, product_id, shade_name_ar, shade_hex, sku, price, stock.

الأقسام (Categories): id, name_ar, slug, parent_id.

الطلبات (Orders): id, user_id, status, total_amount, shipping_address, aramex_awb_number, tracking_status, created_at.

عناصر الطلب (Order_Items): id, order_id, product_id, variant_id, quantity, price.

4. الربط البرمجي مع شركة الشحن الدولية أرامكس (Aramex Integration API)
توفير كود كـ Node.js / TypeScript للربط المباشر مع Aramex APIs:

التحقق من العنوان (Address Validation API): للتحقق من اسم المدينة، الدولة، والرمز البريدي الدولي.

حاسبة أسعار الشحن (Rate Calculator API): لجلب تكلفة الشحن المباشرة بناءً على دولة الوجهة ووزن الطرد.

إنشاء بوليصة الشحن (CreateShipment API): توليد بوليصة الشحن (AWB) تلقائياً بمجرد تأكيد الطلب وإرسال بيانات المرسل والمستلم إلى أرامكس.

تتبع الشحنة (TrackShipments API): إنشاء API Route لتتبع حالة الشحنة برقم البوليصة وتحديث حالة الطلب في قاعدة البيانات تلقائياً.

5. التقنيات المطلوبة (Tech Stack)
الواجهة الأمامية (Frontend): Next.js (React) مع Tailwind CSS (دعم rtl:) و Framer Motion للانتقالات والحركات السلسة.

الخلفية وقاعدة البيانات (Backend & DB): Next.js API Routes / Node.js (Express) + PostgreSQL مع Prisma ORM.

إدارة الحالة (State Management): Zustand أو Redux Toolkit لسلة التسوق.

يُرجى توليد مخطط قاعدة البيانات (Schema)، كود الربط الكامل مع API أرامكس، وهيكل المكونات (React/Next.js) باللغة العربية مع دعم RTL.
